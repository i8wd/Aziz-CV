# Aziz — ArchSirius Studio

An animated architecture and interior visualization portfolio for Aziz. The site is a focused, single-page experience with cinematic image movement, scroll reveals, a responsive mobile menu, and links to ArchSirius Studio social channels.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Project images live in `src/assets`. More studio information, custom fonts, and video work can be added without changing the page structure.
